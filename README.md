# Eco-Reto

Aplicación Flask para registrar acciones ecológicas del grupo (CRUD) con PostgreSQL en Neon, publicada en Render.

**Tecnologías:** Flask, Jinja2, HTML/CSS/JS, PostgreSQL (Neon), psycopg 3, Gunicorn.

## Variables de entorno
`DATABASE_URL`, `SECRET_KEY`, `APP_USUARIO`, `APP_CLAVE`

## Render
- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn run:app`
